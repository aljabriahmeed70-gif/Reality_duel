# Reality Duel

**The World Is Your Arena.**

MVP prototype for:
- Free challenges
- Talent Profiles
- Discover Talent
- Opportunities
- Company vs Company
- In-app hiring flow

## Run

1. Install Flutter.
2. `flutter pub get`
3. `flutter run`

This first build is a UI/flow prototype. Backend, authentication, video upload,
AI proof verification, payments, notifications, and real interview/video services
are intentionally prepared for the next implementation phase.
