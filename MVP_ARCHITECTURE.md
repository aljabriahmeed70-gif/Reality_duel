# Reality Duel MVP Architecture

## Core modules
- Authentication / Profiles
- Duels
- Proof submission and verification
- Talent Profile
- Discover Talent
- Opportunities
- Company hiring
- Rankings
- Notifications
- Moderation / anti-fraud

## Monetization
Users remain free:
- no fee to create core duels
- no fee to participate
- no fee for the basic Talent Profile
- no fee to apply for opportunities

Business revenue:
- employer hiring success fees
- company talent-search tools
- sponsored duels / championships
- institutional talent discovery and scholarship programs
- advanced verification/reporting for employers

## Hiring flow
Job posting -> talent discovery -> application/invite -> interview -> offer -> hire confirmation -> employer success fee.

## Important product rule
Money must never buy a higher duel score, verified achievement, or guaranteed opportunity.
