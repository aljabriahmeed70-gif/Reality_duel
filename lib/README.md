# Reality Duel v0.4

Mobile-first product prototype for Reality Duel.

This release expands the foundation with:
- Talent and Company onboarding
- Talent Profile
- Company Profile
- Duel creation and detail flow
- Proof submission UI (video/photos)
- Verification status model
- Discover Talent
- Opportunities
- Hiring pipeline
- Rankings
- Local demo state

Important: this is still a prototype. Authentication, cloud database, media storage,
real verification, moderation, messaging, payments and push notifications are not
connected yet.

The product rule remains: core participation is free for talent.
